# Hardness与评测

[返回总览](../00_研究方向总览.md)

## 前沿与问题

从一个总分转向可操纵、可归因、可跨模型比较的难度。数学任务的计算图、视觉场景复杂度和视频实体歧义提供不同的控制轴。

最重要的未解决问题是：难度是题目的属性，还是模型与题目、提示、工具、预算共同作用的结果？难度指标在一个模型上有效，不代表换模型仍有效。

## 阅读顺序

先读MathGAP、LILO与InfiniBench，再把NarrativeTrack作为跨模态延伸。优先检验难度排序的跨模型稳定性。
