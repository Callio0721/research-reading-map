# 多模态推理与感知

[返回总览](../00_研究方向总览.md)

## 前沿与问题

从图片问答扩展到视觉草稿、代码工具、视频时序及显式视觉证据。部分前沿方法把看、想、动交替进行。

感知失败与逻辑失败容易混淆；长推理可能缺少图像依据；语言正确但视觉证据错误的轨迹仍可能获得好分数。

## 阅读顺序

先选一篇可控评测，再读CodeV等训练方法；对同一题分别增加图像信息与推理预算，观察哪个改变结果。
