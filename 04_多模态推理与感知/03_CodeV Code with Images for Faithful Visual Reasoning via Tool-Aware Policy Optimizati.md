## 核心内容与阅读价值

将视觉工具表达为Python代码，在SFT后通过TAPO对工具行为给予过程奖励，强调调用工具与实际图像证据的一致性。

## 问题与研究连接

困难样本需要更多工具还是更好的感知？最终答对是否掩盖工具调用不忠实？适合难度分层分析。
